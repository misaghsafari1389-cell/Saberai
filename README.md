# SABER AI V6 PRO

دستیار فارسی مبتنی بر وب با رابط RTL و تم تیره سبز/فیروزه‌ای، گفت‌وگو با Groq، ذخیره تاریخچه محلی و امکانات گفتار وابسته به مرورگر.

## محتویات
- `index.html`: برنامه اصلی
- `manifest.json`: تنظیمات PWA
- `sw.js`: کش رابط و فایل‌های ثابت برای دسترسی محدود آفلاین
- `assets/`: لوگوی متحرک و آیکون‌های PWA (192، 512 و maskable)
- `TEST-REPORT.md`: وضعیت آزمون‌ها و محدودیت‌ها
- `CHANGELOG.md`: تغییرات این نسخه

## انتشار در GitHub Pages
1. فایل ZIP را استخراج کن.
2. ZIP را استخراج کن و محتویات پوشه `SABER-AI-V6-PRO-FIXED` را مستقیماً در ریشه مخزن GitHub قرار بده، نه فایل ZIP و نه پوشه تو در تو.
   **نکته:** آپلود ZIP به‌تنهایی باعث استخراج خودکار فایل‌ها در GitHub نمی‌شود. پوشه `assets/` باید واقعاً در مخزن دیده شود.
3. در `Settings > Pages` گزینه انتشار از Branch اصلی و پوشه `/(root)` را انتخاب کن.
4. سایت را با HTTPS باز کن. Service Worker و برخی قابلیت‌های صوتی به محیط امن نیاز دارند.
5. پس از انتشار، آزمایش اتصال API را از تنظیمات اجرا کن.

## نصب روی اندروید
در Chrome صفحه منتشرشده را باز کن، منوی مرورگر را بزن و در صورت نمایش گزینه `Install app` یا `Add to Home screen` از آن استفاده کن. نمایش گزینه نصب به نسخه مرورگر و شرایط PWA بستگی دارد.

## تنظیم API
1. از منوی برنامه وارد تنظیمات شو.
2. کلید Groq را وارد کن یا فایل TXT/JSON انتخاب کن.
3. کلید را ذخیره کن و سپس «آزمایش واقعی اتصال» را اجرا کن.
4. برای JSON، کلید در فیلدهای `apiKey`، `api_key`، `key` یا `groq_api_key` پذیرفته می‌شود.

**هشدار امنیتی:** این برنامه یک سایت استاتیک است. کلیدی که در مرورگر ذخیره می‌شود، از دید کاربر همان دستگاه یا کد مخرب اجراشده در همان مبدأ محرمانه نیست. برای سرویس عمومی، کلید اختصاصی کاربر را به‌کار ببر یا درخواست‌ها را از بک‌اند امنی عبور بده. کلید اصلی سرویس را هرگز در HTML، مخزن عمومی یا Cache Storage قرار نده.

## حریم خصوصی و محدودیت‌ها
- تاریخچه و تنظیمات در LocalStorage مرورگر ذخیره می‌شوند و از طریق پاک‌سازی داده‌های سایت حذف خواهند شد.
- گفت‌وگوی هوش مصنوعی، به اینترنت و دسترسی معتبر به Groq نیاز دارد.
- تشخیص گفتار، صدای فارسی و نصب PWA به پشتیبانی دستگاه/مرورگر وابسته‌اند.
- Service Worker فقط رابط و فایل‌های ثابت را برای استفاده آفلاین محدود کش می‌کند؛ API در حالت آفلاین کار نمی‌کند.
- این پروژه بک‌اند اختصاصی ندارد و محدودیت مصرف/اعتبارسنجی کلید در سمت سرور پیاده‌سازی نشده است.
