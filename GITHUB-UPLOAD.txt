راهنمای آپلود SABER AI در GitHub (مخصوصاً گوشی اندروید)

GitHub در صفحه Upload files معمولاً پوشه خالی یا خودِ پوشه را مثل فایل مستقل قبول نمی‌کند. باید فایل‌ها و زیرپوشه‌ها را داخل همان صفحه انتخاب/رها کنید، یا از GitHub Desktop/رایانه استفاده کنید.

روش پیشنهادی روی گوشی:
1) ZIP را از حالت فشرده خارج کنید.
2) در مخزن GitHub، مطمئن شوید در مسیر اصلی مخزن هستید.
3) Add file > Upload files را بزنید.
4) در فایل‌منیجر، فایل‌های داخل پوشه پروژه را انتخاب کنید. اگر انتخاب پوشه ممکن نیست، از رایانه یا GitHub Codespaces استفاده کنید.
5) پوشه assets و فایل‌های داخل آن باید حفظ شوند؛ ساختار نهایی باید شامل index.html، manifest.json، sw.js و assets/ باشد.
6) Commit changes را بزنید و در Settings > Pages شاخه و پوشه انتشار را انتخاب کنید.
7) آدرس Pages را باز کنید و یک بار کش سایت را پاک/سایت را دوباره بارگذاری کنید.

نکته: خود ZIP را در مخزن آپلود نکنید و انتظار نداشته باشید GitHub آن را خودکار منتشر کند. محتویات ZIP باید در ریشه مخزن قرار بگیرند.
